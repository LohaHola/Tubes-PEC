# Data Wilayah Indonesia

File JSON di folder ini merupakan salinan lokal dataset provinsi dan kabupaten/kota Indonesia dari [izzulabadi/api-wilayah-indonesia-2026](https://github.com/izzulabadi/api-wilayah-indonesia-2026), versi/tag `v1.0.4`.

- `indonesia-provinces.json`: 38 provinsi.
- `indonesia-regencies.json`: 514 kabupaten/kota.
- Data diunduh dan diverifikasi pada 20 November 2026.
- Kode wilayah dan nama mengikuti dataset sumber. Data dibundel agar dropdown alamat Arbyte tidak bergantung pada API eksternal ketika aplikasi berjalan.
